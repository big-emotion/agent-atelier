# The measured record

What was actually published and what it produced. **This file is updated from
measurement, never from expectation** — on EthniAfrica the numbers come from
`/ethniafrica-audience-audit`, which writes dated reports to `docs/audience/`.

A doctrine rule with no line in this file is a borrowed rule, and the pattern
that carries it says `borrowed`.

## EthniAfrica — YouTube, September 2026

Channel size at measurement: **16 subscribers**. Measured 2026-09-07.

| Video | Hook shape | Exit re-open | Views |
| --- | --- | --- | --- |
| Nigeria | flat impossible assertion | yes | **861** |
| Afrique | direct question, after a scale statement | no | 706 |
| Lingala | — (not recorded here) | no | 632 |
| Channel presentation | none — no loop opened | no | **13** |

What this supports:

- **A video with no open loop has no retention floor.** 13 against 632–861, same
  channel, same period, comparable production. This is the strongest single
  observation in the record.
- **The flat assertion outperforms the question.** 861 against 706 — one week,
  one channel, two data points. A direction to prefer, not a law to cite.
- **The exit re-open is present only on the best performer.** One occurrence.
  Promising, unproven; re-check when a fourth short ships.

Caveats that must travel with these numbers: three videos, one channel, tiny
subscriber base, no controlled comparison, and the subjects differ as much as
the shapes do. Nigeria may lead because it is Nigeria.

## How to add to this file

Add a row when a piece has been **published and measured**, with the date of
measurement and the channel size at that date. Never add a projection. When a
number contradicts a doctrine rule, change the rule and record the contradiction
— a doctrine that only accumulates confirmations is not being measured.
